Below is a summary of the issues addressed in the 5.3.3 release of RocketMQ. For full documentation of the release, a guide to get started, please refer to <a href='/docs/quickStart/01quickstart/'>Quick Start</a>.

## What's Changed
This version no longer supports "ACL 1.0" related features, please use "ACL 2.0".
Additionally, this minor version includes several general bug fixes.
